<original_problem_statement>
The user wants to build a mobile delivery management application named Intercourier Corvo for iOS and Android using Expo.

**PRODUCT REQUIREMENTS:**

1.  **Authentication & Roles:**
    *   Two user roles: Administrator and Deliverer.
    *   Admins create and manage all user accounts (username, password, name, role).
    *   The login system should be based on username and password.
    *   A default user  with password  should exist.

2.  **Administrator Features:**
    *   Create, manage, activate/deactivate, and delete deliverer accounts.
    *   Track individual deliverer statistics.
    *   View all completed and pending deliveries.
    *   Upload a manifesto (delivery manifest document). The app should automatically parse this document to create multiple delivery entries.
    *   Generate and export daily closing reports in Excel and PDF format.

3.  **Deliverer Features:**
    *   **Delivery Creation:** Manually register new deliveries with client data, address, email, notes, and a tracking code.
    *   **Delivery Picagem (Scanning/Lookup):**
        *   Use the device's camera to scan a barcode on a package to retrieve the delivery details.
        *   The scanned package must match an entry from an uploaded manifest.
        *   Alternatively, manually enter the tracking code.
    *   **Proof of Delivery:**
        *   Capture a digital signature from the client directly on the screen.
        *   Take a photo as proof of delivery.
    *   **Status Updates:** Mark deliveries as completed and update status in bulk.
    *   **PDF Receipt:** After a delivery is completed and signed for, the app must be able to generate a PDF receipt containing the delivery date, time, and the captured digital signature.
    *   **View Deliveries:** View a list of their own assigned deliveries.

4.  **Dashboard:**
    *   A main dashboard with key performance indicators (KPIs) and quick actions.
</original_problem_statement>
